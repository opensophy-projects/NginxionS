# Собственные обходы и ложные срабатывания (label 0 / 1)

Формат файла `*.json`:

```json
{
  "label": 1,
  "category": "sqli-bypass",
  "requests": [
    {"method": "GET", "url": "/?q=1' UNION SELECT 1,2,3--", "headers": {}, "data": ""}
  ]
}
```

- `label: 1` — атака, которую модель должна научиться блокировать (обход, найденный в проде).
- `label: 0` — легитимный запрос, который модель блокировала ошибочно (ложное срабатывание).
- `category` — категория атаки для группировки и отчётов.
- `group` формируется автоматически как `case:<имя файла>`.

Положите сюда обходы, которые нашли в продакшене, и легитимный трафик, который блокировался.
Они всегда попадают в обучающую выборку (не делятся на группы по пейлоадам, но имеют свою группу).
